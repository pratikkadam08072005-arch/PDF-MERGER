# 📄 Paperfold – Document Tools

Paperfold is a web-based document processing platform that provides simple and fast tools for working with PDFs, Word documents, and images.

It allows users to merge, convert, and edit documents through a clean and easy-to-use interface.

🔗 **Live Website:** https://merge-pdf-3.vercel.app/

---

## ✨ Features

### 📑 PDF Tools
- Merge multiple PDF files
- Arrange PDFs in the required order
- PDF to Word conversion
- PDF editing

### 📝 Word Tools
- Word to PDF conversion
- Word document editing

### 🖼️ Image Tools
- Image to PDF conversion
- Image to Word conversion
- Image editing

### ⚡ Easy Workflow
1. Select the required document tool
2. Upload your files
3. Process the files
4. Download the generated result
